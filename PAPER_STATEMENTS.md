# Data and code availability

## Data and model availability

Open model checkpoints (`AlphaApta_Model_Checkpoints_v2.tar.zst`), primary single-cell RNA/AbSeq RSEC UMI count matrices and sequence-masked Stage 2 aptamer UMI count matrices (`AlphaApta_SingleCell_Count_Matrices.zip`), and sequence-masked Round-15 Cell-SELEX relative-frequency records (`AlphaApta_Round15_SELEX_SequenceRedacted.tsv.zst`) are deposited at Zenodo under concept DOI [10.5281/zenodo.18242287](https://doi.org/10.5281/zenodo.18242287). All 60 generated candidate sequences from the five-workflow benchmark, the 40-nt scramble control, and the 26-nt AS1411 reference are disclosed in full in `AlphaApta_Source_Data.xlsx` and `Supplementary Tables 7 and 11`. Unmasked Cell-SELEX pool nucleotide sequences and raw co-sequenced FASTQ files remain withheld pending publication of filed patent applications covering candidate aptamer sequences identified in this study.

## Code availability

Source code, audited configurations, and numerical verification scripts are publicly available at [github.com/YangX-BIDD/AlphaApta](https://github.com/YangX-BIDD/AlphaApta).
